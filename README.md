# README
This is the repo for the old version of my personal website (circa 2022)! I created this using Vue 3, Vue Router 4, Node.js, and I used Bulma for styling. I'm currently working on remaking this website with React, but wanted to leave this up for posterity as I am proud of how it turned out and I taught myself the associated frameworks for creating this.

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
